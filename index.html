Result portal

Teachers can import class results from an Excel workbook. After checking the entries, an administrator can publish results for students and parents to search.

Important: This downloadable starter version stores data only in this browser on this device. It is not yet connected to a secure shared database. Do not enter real student information until a secure backend and administrator access have been configured.

Upload marks from Excel or CSV

Use one row per student and include the examination, class, student name, roll number and subject marks. The workbook should have a header row.

Excel files are read in your browser using SheetJS. CSV is also supported. Expected headers: Class, Roll Number, Student Name, English, Urdu, Mathematics, Science, Social Science, Kashmiri. Add or remove subject columns as needed. Maximum marks are configurable in the result view in a future connected version.
