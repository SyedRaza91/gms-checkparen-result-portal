# Govt Middle School Checkparen Result Portal

Static web app with Supabase Auth/Postgres, administrator allowlisting, RLS-protected tables, Excel/CSV import, exam management, publish/unpublish, public published-result lookup and detailed printable marksheets.

Read `SETUP.md` before deployment. The portal is not live until Supabase, Cloudflare Turnstile, Edge Function secrets and Vercel are configured. Never expose the Supabase service-role key in frontend code or GitHub.
